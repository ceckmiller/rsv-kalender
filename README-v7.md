# RSV Kalender Version 7 – Komplettpaket mit Startseite

Die öffentliche Startseite liegt in `docs/index.html` und wird über Netlify unter folgender URL veröffentlicht:

`https://rsv-kalender.netlify.app/`

Diese eine URL kann an Mitglieder, Fans und Mannschaften weitergegeben werden.

## Enthalten

- mobiloptimierte Startseite
- Kalender der 1. Herren
- Kalender der U21
- Google-, Apple- und Outlook-Schaltflächen
- Kopierfunktion für beide Kalender-URLs
- Anleitung zum dauerhaften Abonnement
- Funktionsübersicht für Ergebnisse, Stadion, Navigation, Wetter, OSTSPORT und Vereinsinformationen

## Installation

Den gesamten Inhalt dieses Pakets in das GitHub-Repository hochladen und vorhandene Dateien ersetzen. Anschließend committen und den GitHub-Workflow ausführen.

Netlify verwendet gemäß `netlify.toml` den Ordner `docs` als Veröffentlichungsverzeichnis. Eine weitere Einstellung ist nicht erforderlich.
